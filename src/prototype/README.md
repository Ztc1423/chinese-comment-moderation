# 原型代码说明

本目录是选题 ⑬《中文社区评论审核系统》的**原型代码**，只用于验证接口契约与流程可行性，
不含任何实验结论，也不代表最终实现。三个脚本均仅依赖 Python 标准库，无需安装第三方包。

## 文件

| 文件 | 作用 | 运行 |
|---|---|---|
| `metrics.py` | 统一计分口径：二类宏平均 F1、冒犯类召回率、误杀率、输出有效率，含无效输出计错规则与自测 | `python metrics.py` |
| `label_map.py` | 细粒度标签 → 二分类标签的统一映射；复算数据规模与分布，输出 `data_report.txt` | `python label_map.py`（自测）<br>`python label_map.py train.csv dev.csv test.csv`（真实数据） |
| `agent_loop.py` | 智能体四步循环骨架（初判 → 取证 → 复核 → 终止），三个工具为桩函数，可跑通完整轨迹 | `python agent_loop.py` |

## 已验证

三个脚本均内置自测，在 Python 3.10 上运行通过：

- `metrics.py`：手算样例的宏平均 F1 = 0.5833、误杀率 = 0.5 与断言一致；
  另演示「全判正常」的空模型在 COLD 测试集分布下准确率 0.6042、宏平均 F1 仅 0.3766，
  用以说明主指标为何取宏平均 F1 而非准确率。
- `label_map.py`：4 条细粒度标签（0/1/2/3）映射后与人工判断一致；
  遇到未知标签直接抛错，避免静默出错。
- `agent_loop.py`：3 条演示文本跑通「初判—取证—复核—终止」，
  其中反偏见样本（「不要因为地域就歧视别人」）初判为冒犯、经专用模型与相似案例取证后改判回正常，
  另外两条维持初判且与人工标签一致。

## 必须说明的边界

1. **工具是桩函数。** `classify_comment`、`retrieve_similar`、`check_sensitive` 用规则模拟返回，
   真实版本分别是微调后的 BERT 类模型、训练集向量检索、敏感表达匹配；桩函数**不能**用来汇报指标。
2. **案例库是桩数据。** `agent_loop.py` 中的 `CASES` 仅 4 条示意句，不是 COLD 原文；
   真实实现只允许从训练集检索，绝不包含测试集样本。
3. **不含真实实验结果。** 本目录任何输出都不得写入报告的成绩部分，
   报告中的数字一律取自对官方 csv 的复算与正式评测脚本。

## 接入真实数据

1. 从官方仓库 <https://github.com/thu-coai/COLDataset> 下载 `train.csv`、`dev.csv`、`test.csv` 与 `LICENSE`；
2. 运行 `python label_map.py train.csv dev.csv test.csv`，生成的 `data_report.txt` 用于核对
   37,480 总条数、25,726 / 6,431 / 5,323 的划分，以及测试集 39.6% 的冒犯占比；
3. `agent_loop.py` 中的 `initial_judge` 换为大模型调用、三个工具换为真实实现，循环结构与状态字段不变。
