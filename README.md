# 选题 13 中文社区评论审核系统

这个项目按课程步骤逐步实现。当前已完成 M1 选题和 M2 数据与基准，下一阶段继续在 src 中接入真实模型和检索工具。

| 顺序 | 阶段 | 当前产物 |
| --- | --- | --- |
| 1 | M1 选题与原型 | 任务定义、原型接口、标签映射和指标函数 |
| 2 | M2 数据与基准 | 固定开发与验收划分、冻结记录、沿用 M1 函数的统一判分入口 |
| 3 | 后续实现 | 在现有原型上接入真实模型、单次大模型和检索工具，沿用 M2 评测 |

- [src](src) 保存项目代码。统一评测入口为 `src/m2.py`，Agent 原型和复用模块在 `src/prototype/`。
- [data](data) 保存固定的开发与验收编号及 M2-v1.0 冻结记录。原始评论和验收答案按课程约定单独保管。
- [报告](报告) 保存 M1 和 M2 的阶段报告。
- [模板](模板) 保存课程实验报告模板。

从项目根目录执行 `python src/m2.py selftest` 可检查评测入口。数据复算和评测命令见 [运行说明](运行说明.md)。
